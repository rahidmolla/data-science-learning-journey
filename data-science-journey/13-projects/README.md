# Portfolio Projects

Build these projects end-to-end. Use a legal, documented dataset and never publish private or personally identifiable data.

## 1. Retail sales analysis
**Questions:** How does revenue vary by month, category, region and customer segment? Which products contribute most? Are there seasonal patterns?

**Skills:** pandas IO, cleaning, GroupBy, merge, statistics, Matplotlib/Seaborn/Plotly.

**Deliverables:** Clean dataset or reproducible pipeline, EDA notebook, 6–10 meaningful charts, executive summary, limitations.

## 2. Sports performance analysis
**Questions:** Which players/teams have consistent performance? How do role, venue, opponent and time period affect metrics?

**Skills:** API/file ingestion, data cleaning, feature definitions, groupby, rolling metrics, visualization.

**Deliverables:** Metric dictionary, analysis notebook, player/team comparison dashboard, caveats about sample size and context.

## 3. Customer behavior analysis
**Questions:** Which segments have different order values or repeat purchase patterns? What does retention look like?

**Skills:** joins, date operations, cohort tables, missingness, categorical analysis and dashboard design.

**Deliverables:** Reproducible analysis, cohort chart, segment report, data privacy note.

## 4. Public dataset quality audit
**Questions:** What data-quality issues exist? How much data is affected? Which cleaning decisions change the conclusions?

**Skills:** validation, missing data, duplicates, outliers, type conversion, reporting.

**Deliverables:** Quality report, before/after summary, documented rules, tests.

## 5. Interactive EDA dashboard
**Questions:** What filters and metrics help a stakeholder explore a dataset?

**Skills:** Streamlit, Plotly, caching, input validation, dashboard UX.

**Deliverables:** App source, requirements, screenshots, setup instructions and limitations.

## Project definition of done
- [ ] Dataset source and license documented
- [ ] Raw data kept separate from processed data
- [ ] Data dictionary included
- [ ] Cleaning choices justified
- [ ] Analysis is reproducible
- [ ] Charts have titles, units and interpretation
- [ ] Conclusions include caveats
- [ ] README explains setup and how to run
