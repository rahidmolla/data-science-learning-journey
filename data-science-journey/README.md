# 📊 Data Science Journey

### From Full-Stack Development to Data Science | Learning in Public

Welcome to my **Data Science Journey** repository!

This repository documents my transition from Full-Stack Development to the world of Data Science, Data Analytics, and Machine Learning.

After gaining experience in Full-Stack Development and working on different projects, I decided to explore another exciting area of technology: **Data Science**.

I wanted to understand how raw data is collected, cleaned, processed, analysed, visualised, and transformed into meaningful insights.

That's where my journey began.

Instead of learning only through tutorials, I decided to follow a structured learning approach involving:

- Deep conceptual understanding.
- Exploring libraries, functions, methods, and parameters.
- Hands-on coding and experimentation.
- Solving practice questions.
- Working with real-world datasets.
- Performing data analysis and case studies.
- Building practical projects.

I organised my initial learning journey into an intensive **20-day Data Science learning and practice sprint**.

This sprint covers Python data libraries, statistics, data gathering, data cleaning, exploratory data analysis, visualization, preprocessing, and introductory Machine Learning.

# 🚀 My 20-Day Data Science Learning Journey

## 📅 Complete Day-wise Learning & Practice Roadmap

| Day | Technology / Topic | Learning and Practice Focus |
|---|---|---|
| **Day 01** | NumPy Fundamentals | Introduction to NumPy, installation, arrays, array creation, dimensions, attributes, data types, indexing, and slicing. |
| **Day 02** | NumPy Array Operations | Reshaping, flattening, transpose, copying, views, iteration, stacking, splitting, joining, and concatenation. |
| **Day 03** | NumPy Mathematical & Advanced Operations | Broadcasting, arithmetic operations, universal functions, aggregation, statistical functions, Boolean indexing, filtering, sorting, and searching. |
| **Day 04** | Pandas Series & DataFrame | Series, DataFrame, creation, indexing, attributes, reading CSV/Excel files, inspecting datasets, and understanding data structures. |
| **Day 05** | Pandas Indexing & Data Manipulation | `loc[]`, `iloc[]`, filtering, sorting, conditional selection, adding/removing columns, `apply()`, `map()`, `replace()`, and type conversion. |
| **Day 06** | Pandas Data Cleaning | Missing values, duplicates, `dropna()`, `fillna()`, `isnull()`, `drop_duplicates()`, inconsistent values, and data type correction. |
| **Day 07** | Pandas GroupBy & Aggregation | `groupby()`, `agg()`, `mean()`, `sum()`, `min()`, `max()`, `count()`, `std()`, pivot tables, and grouped analysis. |
| **Day 08** | Pandas Merging & Advanced Operations | `merge()`, `join()`, `concat()`, inner/left/right/outer joins, MultiIndex, datetime operations, string methods, and cross-tabulation. |
| **Day 09** | Statistics Fundamentals | Population, sample, mean, median, mode, range, variance, standard deviation, quartiles, percentiles, and measures of dispersion. |
| **Day 10** | Probability & Statistical Analysis | Probability, conditional probability, distributions, normal distribution, binomial distribution, correlation, covariance, and sampling. |
| **Day 11** | Data Gathering & Collection | Understanding data sources, structured and unstructured data, CSV, Excel, JSON, databases, APIs, web scraping fundamentals, and Python `requests`. |
| **Day 12** | Data Cleaning & Data Preparation | Handling missing and duplicate data, inconsistent records, outliers, incorrect formats, data validation, transformation, and data quality. |
| **Day 13** | Matplotlib | Figure, axes, subplots, line plots, bar charts, histograms, scatter plots, pie charts, box plots, styling, labels, legends, and customization. |
| **Day 14** | Seaborn | Statistical visualization, distribution plots, categorical plots, relational plots, heatmaps, pair plots, joint plots, FacetGrid, and figure-level plotting with `relplot()`. |
| **Day 15** | Plotly & Interactive Visualization | Plotly Express, Graph Objects, interactive charts, scatter plots, bar charts, line charts, histograms, box plots, heatmaps, and dashboard-oriented visualization. |
| **Day 16** | Additional Visualization Technologies | Introduction to Altair, Bokeh, Folium, and GeoPandas; interactive charts, geographical visualization, and mapping data. |
| **Day 17** | Exploratory Data Analysis (EDA) | Univariate, bivariate, and multivariate analysis, distributions, relationships, outlier detection, correlation analysis, pattern discovery, and insight generation. |
| **Day 18** | Data Preprocessing & Feature Engineering | Encoding categorical variables, label encoding, one-hot encoding, normalization, standardization, scaling, train-test splitting, and feature engineering. |
| **Day 19** | Scikit-learn Fundamentals | Introduction to Scikit-learn, estimators, transformers, pipelines, preprocessing tools, train-test split, basic supervised learning, and model evaluation fundamentals. |
| **Day 20** | Integrated Data Science Case Study | Collecting a dataset, cleaning it, analysing it with NumPy and Pandas, visualising insights with Matplotlib/Seaborn/Plotly, preprocessing features, and building an introductory Scikit-learn model. |
