# Contributing and maintaining your learning notes

- Keep examples small, runnable and version-aware.
- Show expected output where deterministic.
- Explain parameters that change behavior, especially `axis`, `inplace`, `skipna`, `how`, `join`, `observed`, and `random_state`.
- Prefer public APIs; flag deprecated APIs instead of teaching them as defaults.
- Never commit private data, credentials, or datasets without a suitable license.
- Add chart images to `assets/` and include the source code that generated them.
- For each lesson, include all 10 learning sections from `templates/lesson-template.md`.
